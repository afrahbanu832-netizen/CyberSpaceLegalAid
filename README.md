# CyberSpaceLegalAid

An AI-powered Multi-Agent Legal Aid System for Cyber Crime victims in India.

This project helps users understand cyber fraud cases, find relevant IT Act sections, and generate a proper complaint draft.

## Features
- Multi-Agent System: Intake Agent, Legal Research Agent, Drafting Agent
- Automatic detection of cyber crime type (UPI Fraud, Phishing, etc.)
- Suggests relevant sections of IT Act 2000
- Generates ready-to-use complaint draft for Cyber Cell / Police
- Simple and clean Web UI

## Tech Stack
- Python
- Flask
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
   git clone https://github.com/afrahbanu832-netizen/CyberSpaceLegalAid.git
2. Install requirements
   pip install -r requirements.txt
3. Run the app
   python app.py
4. Open in browser
   http://127.0.0.1:5000
